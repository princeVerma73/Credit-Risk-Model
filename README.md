# PV Finance – Credit Risk & Loan Default Prediction

A machine learning–based web application that predicts **loan default probability, credit score, and risk rating** using applicant financial and behavioral attributes.

🔗 **Live App**: https://prince-credit-risk-modeling.streamlit.app/

---

## Overview

This project demonstrates an end-to-end **credit risk modeling pipeline** commonly used in banks and NBFCs.  
Users input loan and credit-related information, and the system estimates default risk along with a credit score.

---

## Features

- Loan default probability prediction  
- Credit score generation (300–900 scale)  
- Risk rating: Poor / Average / Good / Excellent  
- Interactive Streamlit-based UI  
- Deployed on Streamlit Cloud  

---

## Tech Stack

- Python 3.10  
- Scikit-learn  
- XGBoost  
- Pandas, NumPy  
- Streamlit  
- Joblib  
- Optuna
